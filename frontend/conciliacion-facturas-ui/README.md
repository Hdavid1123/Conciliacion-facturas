# Frontend — Conciliador de Facturas

## Ejecución

```bash
ng serve
```

La aplicación estará disponible en `http://localhost:4200`.

## Build

```bash
ng build
```

## Tests

```bash
ng test
```

## Estructura

```text
src/app/
├── app.ts              # Componente principal
├── app.html            # Template
├── app.css             # Estilos
├── app.config.ts       # Configuración
├── app.routes.ts       # Rutas
└── conciliacion.service.ts  # Servicio HTTP
```
